# Art drop folder

Put generated artwork here, one folder per asset ID (for example `ArtDrop/CHR-01/`). Unity does not import this folder; accepted art is moved into `Assets/Art/` after review.

Read these first, in `Docs/Art/`:
- `HANDOFF.md`: naming, sizes, transparency, number of variants, and the delivery log.
- `ASSET_LIST.md`: which assets are needed and in what priority.
- `PROMPTS.md`: ready-to-use prompts for every P1 and P2 asset.
- `ART_BIBLE.md`: the target style.
- `CRITIQUE_RUBRIC.md`: how each image will be judged.

Start with CHR-01 (Samuel) and BG-02 (community meeting area). Both must be approved before the rest of the cast and scenes, because they set the style reference.
